# Additional experiments: statistical and computational protocol

This additive source package targets the uploaded Holder–Bayes source snapshot. It invokes the original targets, generators and `hbayes.paper_sampling.fit`; it does not invoke a replacement posterior sampler. For the joint DPD target, the native backend fits a NUTS proposal and then uses frozen-mixture independence Metropolis–Hastings. Downstream Gaussian-likelihood Bayesian refits use native NUTS. Original repository files are unchanged. No archived result, reference table or provenance folder is needed.

## Direct comparison

The primary grids match the original principal settings: diagonal Gaussian density, scenario A, n=1000, epsilon in {0,.1,.2,.3,.4}, gamma=.5, 30 replications; homogeneous-response Gaussian linear regression, n=1000 and clean test n=1000, two covariates, shift 6, epsilon in {0,.05,.1,.2,.3,.4}, gamma=1, 30 replications. Original random-seed formulas and float32 generator coordinates are preserved. Inference promotes inputs locally to float64 as the native code does.

Benchmarks use cal_housing (20640x8), kin8nm (8192x8), pumadyn32fh (8192x32), five 80/20 splits, gamma=.5, epsilon in {0,.2}. Original train/test seeds, clean-train Kanamori standardisation, and additive N(6,1) response injection are used. The same clean-train scaler is reused for fitting and clean-test prediction. The clean-train scaler is part of this semi-synthetic design; it is not a practical unknown-contamination preprocessing recommendation. Full dataset shapes are validated. Downloaded/local raw arrays are cached with the run; saved likelihood arrays are hashed. A reused cached dataset remains the input of that run even if the external source changes.

Methods are frequentist point, H-B point and FoD. Optional `direct.bootstrap_B > 0` adds the Bootstrap score/centre; its default is zero because the second study is the primary uncertainty comparison. No external literature baseline is replaced in the original experiment runner.

Let alpha=1-epsilon, A=integral p_theta^(1+gamma), B=mean p_theta(x_i)^gamma (conditional response density in regression). The exact native DPD-type score, up to its shared positive convention, is

`S(theta, alpha) = gamma * alpha^(1+gamma) * A - (1+gamma) * alpha^gamma * B`.

At fixed theta, alpha_hat=min(1,B/A). The frequentist estimator profiles alpha analytically and minimises over theta with an analytic envelope gradient and L-BFGS-B from multiple starts. It has no prior or temperature. Starts include least squares/robust regression or central/cluster density fits, followed by random subsets. All candidate starts and finite attained objectives are retained. Projected-gradient tolerance is 1e-4. Solver success is also recorded; numerical validity uses stationarity rather than the solver's message alone.

Numerical support: location/regression coefficients lie in [-50,50], scales in [.05,10], in fitted coordinates. Hitting a coefficient or upper-scale boundary is invalid; hitting the lower scale bound is retained and explicitly reported. The original regression H-B target already restricts scale to at least .05; original density H-B has no floor. Thus the density baseline is explicitly constrained and not support-matched at its lower boundary. Gaussian-mixture empirical objectives can collapse; floor hits require inspection and floor sensitivity. No global optimum is claimed. `optimizer` exposes starts, support and tolerances; use a new output directory for any changed setting. Bootstrap uses the same support, objective, validity criterion and full-fit anchor, with eight starts instead of sixteen by default.

H-B temperature and priors are the native empirical choices, with configurable positive `sampler.eta_multiplier`, `beta_prior_sd` and `log_scale_prior_sd` for sensitivity. Defaults are unchanged (location/coefficient SD 10, log-scale SD 1, native prior on alpha). H-B point centres average coefficients/location and log-scales in native coordinates, and use the FoD central count. FoD uses up to 2000 evenly spaced draws balanced over chains; the averaged selected count is rounded for its central removal set. The epsilon estimate itself averages all posterior draws. Each draw removes round(n*epsilon) observations of smallest fitted density. Quantised FoD ties use posterior-mean severity, then observation order. Point severity is negative fitted log density.

Report epsilon absolute error (optionally derive RMSE from raw estimates), location/scale or coefficient errors, clean-test RMSE/MAE, AP/AUC/F1 and errors of the central removal set. AP is provided both with raw ties (`AP`) and with the deterministic complete ranking (`AP_rank`). At epsilon=0 or a realised single-class sample, AP/AUC are undefined and recorded missing, not zero. Matched 10%/20% removal-budget detection rows are kept separately from estimated-count rows. HB-point/FoD initial estimation errors coincide by construction; their distinction is the audit ranking, not parameter estimation.

For regression, removal is followed by the same downstream estimator for every method, including no cleaning. The full default uses native Gaussian-likelihood Bayesian refitting with the original priors and fixed original scaler. The OLS option is a cheaper auxiliary/pilot setting. A refit that is rank-deficient or fails diagnostics is recorded. Cleaning summaries require all methods' refits in a replicate to succeed.

## Cost study

The new study is deliberately separate from the original paper DGP. Grids are n in {50,150}, p in {1,5}, symmetric response shifts in {2.5,6}, Bernoulli epsilon=.15, gamma in {.5,1}, 20 replications. Two clean controls are n=50,p=5 and n=150,p=1. X initially has covariance Sigma_ij=.5^|i-j|. Independently of contamination, 20% of covariate rows are multiplied by three, giving population covariance 2.6*Sigma. Equal slopes are normalised to give population signal variance one. Y=X beta+N(0,1)+Z*shift*sign, with independent signs +/-1. High leverage can increase ranking sensitivity to theta uncertainty; no favourable outcome is assumed.

The observed training data set the fixed feature/response scaler. Within each n,p,replicate, covariates, noise, latent uniforms and signs are the same across gamma and shift. Base seed is 202611030 and data seed is base+10000*p+100*n+rep. True contamination labels are never given to inference, the optimiser, the audit construction or the action rule.

Pairs bootstrap resamples n observed (X,Y) pairs with replacement, uses count weights in the same objective, and evaluates every fitted bootstrap selector back on the ORIGINAL n observations. The original scaler remains fixed. It estimates uncertainty of the fitted audit procedure, not probabilities of true contamination. All B=200 fits remain in the saved checkpoint and audit score, including numerical diagnostic failures. If any bootstrap fit fails validity, the setting is not a common valid pair; bootstrap draws are never selectively discarded. Deterministic per-bootstrap seeds permit resumption without changing later draws.

The six method variants are frequentist hard selection, H-B point hard selection, joint FoD, bootstrap membership frequency, epsilon-only uncertainty (theta fixed at its posterior mean) and theta-only uncertainty (all draws use the rounded mean audit count). The two ablations describe frozen components of the audit procedure; they do not constitute an additive causal decomposition of correlated posterior uncertainty.

For membership score q, the proxy action minimises among keep cost C_FN*q, remove cost C_FP*(1-q), and verify cost C_V. Point baselines use their binary central selectors as q. Ties prefer keep, then remove, then verify. q is not assumed calibrated to the latent label, so these are proxy-risk actions, not asserted Bayes-optimal actions for true contamination. Evaluate on the simulator truth using

`loss = (C_FP * false_removals + C_FN * missed_outliers + C_V * reviews) / n`.

Primary C_FN=1, C_FP in {1,5,10}, C_V in {.1,.5}; primary display gamma=.5, C_FP=5,C_V=.1. Review is perfect by default. Optional symmetric reviewer error r adds expected error cost r*(C_FP*reviewed_inliers+C_FN*reviewed_outliers)/n. This sensitivity holds the original policy fixed, instead of claiming to re-optimise under reviewer noise.

Two controls address different mechanisms: `matched_FoD_workload` gives each ranking the SAME number of automatic removals and reviews as FoD, removing the most severe D observations and reviewing the next R; `fixed_triage` uses common q<=.1 keep / .1<q<.9 verify / q>=.9 remove thresholds. Keep-all and review-all are included for the proxy-risk rule. Save loss, mistakes and workload together; any advantage can arise from allocating reviews rather than improved ranking. No threshold/cost is tuned on truth.

Auxiliary downstream results compare central hard-cleaning OLS, soft WLS with weights 1-q, and unfiltered OLS. These are not the post-verification action policies. Exact clean-population prediction RMSE is sqrt(1+intercept_error^2+slope_error'*(2.6*Sigma)*slope_error), evaluated after converting fitted coefficients back to original coordinates. Too few effective observations/rank deficiency is recorded, never silently replaced by OLS.

## Diagnostics, summaries and reproducibility

Default H-B: 4 chains, 4000 warmup and 4000 posterior draws per chain; if diagnostic criteria fail, retry with 8000 draws. R-hat <=1.01 and bulk/tail ESS>=400 are required. Proposal NUTS divergences are retained for inspection; they are not divergences of the final MH chain. NLL refits additionally require zero native NUTS divergences. Native diagnostics and all repair attempts remain on disk. Short smoke settings retain these thresholds and do not establish convergence.

Every planned cell remains in completion accounting. Raw tables retain results failing diagnostics; primary summaries use complete common valid pairs (HB, frequentist, all bootstrap fits when requested). This is explicitly a conditional numerical-validity summary, potentially selective: inspect the failure pattern, report exclusions, and increase computational effort or revisit the numerical restriction if failures are substantial. It is not acceptable to report a favourable aggregate while hiding failed cells.

Cost differences pair FoD and comparator within the SAME cell/replicate/cost/rule. For macro intervals, first require the entire contaminated n,p,shift grid to be valid within each gamma/replicate/cost/rule, then equally average its condition differences, then bootstrap those replicate blocks 4000 times with fixed seed. Clean controls are separate. Negative loss differences favour FoD. The number of complete blocks is shown alongside the planned count. A single block has no interval. With 20 replicates, intervals are descriptive simulation uncertainty, not evidence of deployment-wide guarantees.

The output manifest binds configuration, Python/major dependency versions and scientific Python sources. Per-job inputs and committed output hashes are checked; changed runs require a new output directory. Native cache contracts independently verify target/data/sampler compatibility. Files commit atomically; per-job OS locks release on process exit. Bootstrap resume diagnostics and draws commit together. Concurrent workers use deterministic external job shards. Collection and plotting never initiate inference. Do not mutate a run's inputs or cached results.

Configuration files: full grid `additional_experiments.json`; intermediate execution trial `additional_pilot.json` (not the definitive grid); short integration smoke `additional_smoke.json` (not scientific results). See the Japanese guide for exact commands. Archive contents exclude generated outputs, original sources, package caches and git metadata.
